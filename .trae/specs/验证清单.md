# 连接树结构优化 - 验证清单

## 验证检查点

- [ ] **检查点 1**: 数据类型扩展验证
  - 检查 db-common 库是否包含 TriggerInfo、EventInfo、RoleInfo、TablespaceInfo 等新类型
  - 检查 DatabaseInfo 和 SchemaInfo 是否正确添加了新字段
  - 检查类型定义是否有 #[serde(default)] 等向后兼容特性

- [ ] **检查点 2**: MySQL 驱动更新验证
  - 检查 MySQL 驱动是否有查询触发器的方法
  - 检查 MySQL 驱动是否有查询事件的方法
  - 检查 get_metadata 是否正确收集并返回新类型数据
  - 检查用户数据是否在正确的位置（连接根级别）

- [ ] **检查点 3**: PostgreSQL 驱动更新验证
  - 检查 PostgreSQL 驱动是否支持数据库层查询
  - 检查是否有查询触发器、事件的方法
  - 检查是否有查询角色、表空间的方法
  - 检查 get_metadata 返回的层次结构是否正确

- [ ] **检查点 4**: 树模板更新验证
  - 检查 TREE_NODE_TEMPLATES 是否为 MySQL 定义了完整分类
  - 检查 TREE_NODE_TEMPLATES 是否为 PostgreSQL 定义了完整分类
  - 检查根容器类型是否支持新结构

- [ ] **检查点 5**: ConnectionTree 组件更新验证
  - 检查 TreeNodeType 是否包含新类型
  - 检查 buildCategoryChildren 是否支持新增分类
  - 检查 hasCategoryItems 是否正确检查新分类
  - 检查树构建逻辑是否支持 PostgreSQL 的数据库→模式两层结构
  - 检查新节点类型是否有对应的图标

- [ ] **检查点 6**: 编译验证
  - 检查 Rust 代码是否能正常编译
  - 检查 TypeScript 代码是否能正常编译
  - 检查是否有类型错误

- [ ] **检查点 7**: 功能验证（MySQL）
  - 连接到 MySQL 数据库
  - 检查树结构是否为：连接 → 数据库 → [表、视图、存储过程、函数、触发器、事件]
  - 检查用户是否在正确的位置
  - 检查新对象类型是否能正确显示

- [ ] **检查点 8**: 功能验证（PostgreSQL）
  - 连接到 PostgreSQL 数据库
  - 检查树结构是否为：连接 → 数据库 → 模式 → [表、视图、物化视图、存储过程、函数、触发器、事件、序列、索引] + 角色、表空间
  - 检查新对象类型是否能正确显示
