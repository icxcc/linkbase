# 连接树结构优化 - 实现计划

## [ ] Task 1: 扩展数据库元数据类型
- **Priority**: P0
- **Depends On**: None
- **Description**: 
  - 在 db-common 库中添加新的元数据类型：TriggerInfo、EventInfo、RoleInfo、TablespaceInfo
  - 更新 DatabaseInfo 和 SchemaInfo 结构，添加相应的字段
  - 更新 DatabaseMetadata 结构，支持 PostgreSQL 的数据库层
- **Acceptance Criteria Addressed**: AC-1
- **Test Requirements**:
  - programmatic: 类型定义正确添加，编译通过
- **Notes**: 确保向后兼容，使用 #[serde(default)] 等特性

## [ ] Task 2: 更新 MySQL 驱动
- **Priority**: P0
- **Depends On**: Task 1
- **Description**: 
  - 添加查询触发器的方法
  - 添加查询事件的方法
  - 更新 get_metadata 方法，收集并返回新类型数据
  - 将用户数据从默认数据库移到连接根级别
- **Acceptance Criteria Addressed**: AC-2
- **Test Requirements**:
  - programmatic: 驱动能正常编译并返回包含新类型的元数据
- **Notes**: 使用 information_schema.TRIGGERS 和 information_schema.EVENTS 表

## [ ] Task 3: 更新 PostgreSQL 驱动
- **Priority**: P0
- **Depends On**: Task 1
- **Description**: 
  - 重构元数据查询，添加数据库层
  - 添加查询触发器的方法
  - 添加查询事件的方法
  - 添加查询角色的方法
  - 添加查询表空间的方法
  - 更新 get_metadata 返回正确的层次结构
- **Acceptance Criteria Addressed**: AC-3
- **Test Requirements**:
  - programmatic: 驱动能正常编译并返回新结构的元数据
- **Notes**: PostgreSQL 需要查询 pg_database、pg_roles、pg_tablespace 等系统表

## [ ] Task 4: 更新 TREE_NODE_TEMPLATES
- **Priority**: P0
- **Depends On**: Task 1
- **Description**: 
  - 更新 TreeNodeTemplate 类型，支持更灵活的树结构定义
  - 为 MySQL 定义完整的分类：表、视图、函数、存储过程、触发器、事件
  - 为 PostgreSQL 定义完整的分类：表、视图、物化视图、函数、存储过程、序列、索引、触发器、事件，以及顶级的角色、表空间
  - 更新根容器类型，支持 PostgreSQL 的数据库→模式两层结构
- **Acceptance Criteria Addressed**: AC-2, AC-3
- **Test Requirements**:
  - programmatic: 类型定义正确，编译通过
- **Notes**: 确保模板能正确指导树组件渲染

## [ ] Task 5: 更新 ConnectionTree 组件
- **Priority**: P0
- **Depends On**: Task 4
- **Description**: 
  - 更新 TreeNodeType 类型，添加新类型
  - 更新 buildCategoryChildren，支持新增的分类类型
  - 更新 hasCategoryItems，检查新分类
  - 更新 loadCategoryChildren，加载新分类数据
  - 重构树构建逻辑，支持 PostgreSQL 的数据库→模式两层结构
  - 添加新节点类型的图标
- **Acceptance Criteria Addressed**: AC-2, AC-3, AC-4
- **Test Requirements**:
  - human-judgment: 树组件能正确渲染新结构，新对象类型显示正常
- **Notes**: 保持代码风格一致，避免破坏现有功能

## [ ] Task 6: 验证和测试
- **Priority**: P1
- **Depends On**: Task 2, Task 3, Task 5
- **Description**: 
  - 编译项目，确保没有错误
  - 测试 MySQL 连接，验证树结构
  - 测试 PostgreSQL 连接，验证树结构
  - 检查新对象类型的显示
- **Acceptance Criteria Addressed**: AC-1, AC-2, AC-3, AC-4
- **Test Requirements**:
  - human-judgment: 功能正常，展示正确
- **Notes**: 可以先进行编译验证，再进行功能测试
